# P04G dry impacts

20 оригинальных mono PCM16 WAV, 44.1kHz: 5 категорий × body/concrete/metal/finish. `render.py` — полный воспроизводимый DSP source: damped body sine, short noise attack, sharper cut scrape, resonant metal tail. Использован отдельный seeded RNG только при offline синтезе. Это не запись реального человека/оружия и не клонирование голоса; никаких внешних samples/API/расходов. Музыка P04 неизменна.

`provenance.json` содержит recipe/manifest/PCM SHA256 и численные peak/RMS/clipping metrics. Сигнальный анализ не является listening. Независимое фактическое прослушивание и художественное принятие PENDING; владелец может слушать source WAV или actual mixer replay WAV из native QA.
