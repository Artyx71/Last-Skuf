# LAST_SKUF_DEMO — исходник P03

Оригинальная локальная электронная композиция для прототипа Якудзы: 144 BPM, 4/4, 8 тактов, D minor с A-dominant turnaround. Ровно 640000 стереофреймов при 48000 Hz (13⅓ секунды). Это production candidate с реальными мастерами и runtime media; обязательное восприятие на слух пока не выполнено.

`composition.json` содержит редактируемые ноты, гармонию, ритм баса, форму и adaptive profiles. `render.py` синтезирует каждый звук с нуля, пишет 24-bit PCM WAV, Vorbis OGG и previews. `verify.py` отдельно декодирует готовые файлы, проверяет синхронизацию/пики/стыки, пишет метрики, hashes и предлагаемые строки лицензирования. Внешних recordings, sample packs, melоdies, AI-audio APIs или моделей реальных голосов нет.

Форма AABA по двум тактам: основное тяжёлое синкопированное остинато D, повтор с подхватами/B♭, смещённая вверх Gm→A7 секция B, возвращение Dm→A7. Ударные имеют swing шестнадцатых, дополнительные kick-подхваты, hat rolls и нисходящие tom fills в тактах 4/8. Лид отвечает короткой последовательностью; pad меняет голосоведение и даёт намеренное доминантовое напряжение. Бас состоит из моносаба, затухающего гармонического корпуса, лёгкой сатурации и верхнего bite. Его ритмические запаздывания выражают вес персонажа, без музыкальной пародии.

Все четыре stem всегда имеют одну длину и запускаются вместе. `bass` сохраняет центр; `texture` и `lead` имеют аккуратную стереоширину; wrap delays переносят хвосты через конец цикла. Один общий production gain сохраняет баланс. Профили задаются линейными коэффициентами в manifest; не нормализовать stem по отдельности. Runtime обязан включить loop для OGG и плавно интерполировать профили. Preview восьми состояний — авторская демонстрация, не evidence работы Godot.

В среде рендера использованы Python 3.14.7, NumPy 2.3.5 и FFmpeg n9.0.1/libvorbis. NumPy установлен в временный user-local venv `/tmp/ayay-p03-audio`; system packages не менялись. Если Python/pip уже доступны, создать отдельный venv и установить `requirements.txt`; FFmpeg должен быть в PATH. Затем из корня проекта:

```sh
python assets/source_audio/last_skuf_demo/render.py
python assets/source_audio/last_skuf_demo/verify.py
```

В текущей машине настроенный uv shim не имеет default version. Фактически рабочий executable: `/home/artyx/.local/share/mise/installs/uv/0.13.7/uv-x86_64-unknown-linux-gnu/uv`. Рендер/проверка выполнялись `/tmp/ayay-p03-audio/bin/python`. Никаких sudo или платных сервисов.

Provenance: авторский синтез для проекта, вычислительные осцилляторы и детерминированный шум seed 190371. Код Python/NumPy и FFmpeg — инструменты, их сторонние медиа не включены. Реальный голос и приватные фото не использовались. Исходные данные/генератор позволяют пересоздать PCM; метаданные контейнера OGG могут отличаться при повторном кодировании. Права на публичный выпуск проекта остаются отдельным решением владельца. Предлагаемые CSV строки находятся в `reports/phases/P03/audio_license_rows.csv`; основной CSV этот автор не меняет.
