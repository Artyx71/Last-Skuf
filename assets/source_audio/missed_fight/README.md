# MISSED FIGHT / BACK DOOR — оригинальная музыка P04

Локальный синтез без входных аудиофайлов, сторонних сэмплов и реальных голосов. DSP и исходный renderer развиты из собственного P03 `last_skuf_demo/render.py`; новая партитура в `composition.json`: E minor, Cmaj7, B dominant, 144 BPM, 8 тактов, четыре синхронных stem, 48 kHz / 640000 frames. Тяжёлый бас и металлическая перкуссия; EXPLORE/SUSPICION/COMBAT/CLEAR используют один clock AudioDirector. Единственный новый SFX — синтезированная дверь.

Воспроизведение: Python + numpy 2.3.5 + FFmpeg/libvorbis, `python render.py`. 24-bit WAV masters и OGG — реальные файлы, provenance содержит SHA-256. P03 runtime-файлы не перезаписываются. `render.py` добавляет только новый door cue в общий manifest и обновляет ресурсы своей миссии.

Публичный репозиторий разрешён владельцем; отдельный релиз не разрешён. Сигнальный анализ не означает прослушивания: художественная оценка новых stem и итогового игрового микса ожидается отдельно; прежнее прослушивание P03 на них не распространяется.
