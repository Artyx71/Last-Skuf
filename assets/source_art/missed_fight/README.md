# THE MISSED FIGHT — окружение P04

Авторский пиксельный набор: `render.py` рисует каждый элемент на целочисленной сетке через Pillow. Фото, внешние изображения/генераторы, чужие карты/знаки и сглаживание не используются. Это настоящие PNG с atlas и исходником, а не результаты запуска image_gen. Художественная приёмка независимым человеком ещё не выполнена.

Палитра из 32 цветов, плитки 32×32, предметы 96×96, состояния двери 32×96: закрыто/доступно/открыто. Карта 1152×640 использует `game/resources/chapters/missed_fight.json` для совпадения стен с collision. Раковины, зеркала, кабинки, куртка с ключом, ящики, вентиляция, рольставня, скамейка и столбик нарисованы отдельно; карту не выдают за реальный интерьер.

Воспроизведение: `python render.py` с Pillow 13.0.0. SHA-256 и размеры — `provenance.json`. Runtime — `game/assets/art/missed_fight/`. Рисунок карты — source preview, **не actual engine capture**. Нужны игровые кадры с камерой/актёрами/диалогом и независимая визуальная проверка.
