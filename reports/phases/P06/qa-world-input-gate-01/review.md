# P06 — независимая QA строгого per-sample Engine Input gate

Компонент проверен: новых actionable-дефектов не найдено. Gate действительно отклоняет единичную потерю Engine Input/Shift/velocity, даже когда прежний engine PASS, distance и phasecoverage остаются в исходном JSON. Это bounded QA компонента, не PASS P06, merge, ART, focus, manual keyboard, audio или экспортная приёмка.

Изучены validator,14tests, wrapper verify_p06_world.py и регистрация в common verify.py. План672samples выводится независимо от наблюдаемой анимации:480grid+192continuous, направление и Shift заданы ожидаемым маршрутом; скорость берётся wrapper из configured playable catalog, не из наблюдаемой velocity. Timka84/Ryzhik120 совпадают с fixture Catalog. Проверяются identity/scope/route/count/реальные inputvector/Shift/velocity, допустимый frame index и невозврат physics tick. Boolean и нечисловые значения, NaN/Inf и переполняемые числа отвергаются. Buffer ошибок ограничен40, но итоговая ошибка зависит от всехviolations, не от размера buffer.

Независимо запущена существующая suite14/14 с полными stdout/stderr/exit artifacts и отключёнными bytecode writes. Положительные данные — immutable actualnative02 live/movie, SHA проверены; все1344samples приняты без изменения файлов. Это post-hoc применение нового pure gate к прежним настоящим данным, а не утверждение, что старый native02 уже исполнял новый wrapper.

Дополнительно QA внесла1008faults только в копии реальной трассы в памяти: по одному dropped Input и velocity в каждой из408движущихся позиций и lostShift в каждой из192run позиций, включаяcontinuous. Все1008отклонены; исходный engine passed=true и прежние coarse checks сохранены, после восстановления данные равны original. Проверен случай672пустых sample objects:40сохранённых ошибок,4032violations, FAIL — ограничение logs не превращает ошибку вPASS.

В12изолированных wrapper cases вся native/Git/ffmpeg/ffprobe работа заменена явными mocks, ROOT только TemporaryDirectory; настоящие бинарники/сборки/исполнитель/сеть не запускались. Сценарии валидного headless/movie проходят; singledrop направления/Shift/velocity/continuous, missingobservation и movie-onlydrop приводят кpassed=false/exit1. Ошибка live не запускаетmovie. Прежний engineFAIL, process exitFAIL и sourcechange продолжают блокировать итог, даже если новый signal gate зелёный. Артефакты wrapper-cases являются синтетическими временными wiring tests, не игровыми native evidence.

В2изолированных common verify wiring cases подтверждены настоящая регистрация unittest discover test_p06_world_input.py и распространение ошибки этого gate в общий nonzeroexit. Все остальные subprocess вызовы были mocks; полный common verification/игра не запускались. Число14самих unit cases подтверждено отдельно реальным unittest run, а не выводится из mocked CI.

Авторский новый headless replay70/70 прочитан вместе с5artifactSHA: strictinput672/672, sourceunchanged=true; все6релевантных code/catalog hash совпадают с текущими файлами. Fixture/driver c0dd0099… и Timka WORLD sheet/metadata совпадают с native02: gate не меняет heldkey events, timing, gameplay и не reasserts input. Все reviewed source hash стабильны за время QA. Oldfailed native01 receipt/logSHA неизменны, exit1 сохранён. Добавление новых арт-источников не изменило pinnednative02trace files.

Wrapper использует strict gate в AND с прежними engine/continuous/renderer checks и source_unchanged, пишет его отдельный результат, а общий exit соответствует итоговому passed. Common CI также принимает только нулевой exit. strict_input_verified является отдельным сигналом и не заменяет overall passed: например sourcechange по-прежнему даётFAIL.

Границы: real-world keyboard/focus efficacy намеренно false, focusmetadata не является условием signalPASS. Gate не является независимым ART/performance/position/полным game-schema validator. No full P06 verdict. Для следующего персонажа требуется настоящий новый frozen native replay с новым wrapper; исторические native traces и этот QA не заменяют его. Проверка fullphase harness не входила в данный scope и не служит причиной остановки bounded компонентного review.
