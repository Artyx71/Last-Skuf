# Что должен выполнить контроллер

Это перечень внешних зависимостей, не решение Lead и не новый attempt. Authoritative state остаётся в основном checkout; его snapshot в worktree не менялся.

1. **P04-ENV-01 / BLOCKED:** запустить текущий P04 в окружении, где разрешены локальные X11/Wayland/audio sockets. `native_capture_probe.log` подтверждает отказ обоих display drivers. Выполнить `python3 tools/verify_p04.py --output reports/phases/P04/attempt1/native-followup --build-output build/P04/native-followup --exports --movie`. Нужны настоящие кадры intro/washroom/checkpoint/death/distraction/phone/options/street/complete, обычный и reduced режимы, MovieMaker-видео, реальный device/mixer capture и графические frame timings. Offline MovieMaker/Dummy и actual listening отдельно.
2. **P04-AUDIO-01 / PENDING:** получить реальное прослушивание четырёх новых профилей, двери и итогового игрового микса по `listening_request.json`. Сигнальный анализ новых 5 OGG и 5 миксов этого не закрывает. Не переносить одобрение P03 на новую музыку.
3. **P04-WIN-01 / BLOCKED:** Windows PE экспортирован, но wineserver не может bind socket (`windows_wine_probe.log`). Проверить актуальный бинарник под разрешённым Wine либо native Windows. Native Windows в этой сессии отсутствует; PE magic/export не равны runtime proof.
4. **P04-GIT-01 / BLOCKED:** `git_add_probe.log` — read-only общий `.git/worktrees/P04/index.lock`. Контроллер с правом записи общего gitdir должен проверить file manifest/privacy, затем создать небольшие source/evidence commits на `phase/p04-implementation`. Автор не использовал альтернативный index/ref/object storage для имитации коммита. Не включать `.tools/`, rawphotos, приватные файлы или build binaries >100 MB.
5. **P04-REV-01 / INDEPENDENCE_BLOCKED_IN_EXECUTOR:** назначить отдельный read-only Lead на точный закоммиченный SHA и реальные evidence. В данном исполнителе запрещены subagents/второй Codex; review/decision не создавались. Нужны визуальная оценка карты/коллизий/портрета, русский текст, игровая читаемость и audio listening. Затем обязательный CI того же SHA; PR/push/merge выполняет только контроллер при соблюдении AUTHORIZATIONS.

До выполнения требований не отмечать P04 PASS и не запускать P04G/P05/P07. P04G остаётся обязательной перед P07; новая кровь, finishers и reaction baseline здесь не реализовывались. Никаких permission/protection/visibility/billing изменений для обхода ограничения.
