# GAME_VISION v0.1

## Premise
**АЫАЫ: Последний скуф** — original desktop 2D top-down fast action/dark comedy in Vladikavkaz. Multi-protagonist, nonlinear intersecting campaigns centered on Nikita “Якудза”, who is intentionally not an overpowered action hero.

## Canon currently selected
- Tone: 70% local absurd comedy, 30% crime; serious consequences remain serious.
- Main conspiracy: fictional PRIME, publicly fronted by Maxim “Ментор”; secretly organized in the **fictional game story** by Denis “Кабан”, Yakudza and Olezhka's father.
- Main selected ending: `WIFE CALLING`: Yakudza leaves the climactic confrontation to go home to Ellana; remaining friends finish exposing PRIME.
- Seven primary playable leads: Якудза, Габар, Олежка, Тимка, Рыжик, Тега, Паша. Supporting: Эллана (Жинька), Эля, Кабан; Jack the dog and Akhshar planned, no photo yet.
- Character-driven humor: colloquial Russian profanity, appropriately verified Ossetian expressions, everyday dialogue, distinct speaking voices. No generic exposition dumps.
- Original driving soundtrack (darksynth, breakbeat, electronic percussion) with optionally researched Ossetian musical motifs; original sound effects and reactive music transitions.

## Product constraints
- Native desktop Godot 4.x, Windows and Linux primary; keyboard/mouse, later gamepad.
- Crisp native-resolution pixel art; top-down action, responsive controls, rapid retries, original assets and designs.
- Dialogue composition: in-scene view left, large animated talking portrait right, pixel-text subtitles below; typewriter, skip, controller support. `assets/references/ui/dialogue_layout_reference.png` is a **layout reference only**.
- Real-world crimes, financial acts, medical and relationship anecdotes used here are fictionalized comic material and not factual claims. Get permission before publishing identifiable portrayals.

## Quality gates
One cohesive art style; recognizable portraits; directional sprite consistency; authentic voice; stable input and frame rate; working desktop builds.
