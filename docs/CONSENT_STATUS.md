# Разрешения текущей сессии

Актуальный источник — automation/AUTHORIZATIONS.json; сохранённые решения владельца не требуют повторного разрешения.

- Вначале владелец разрешил создать приватный Artyx71/Last-Skuf и отправить проверенные файлы без фотографий. Затем явно разрешил сделать репозиторий публичным: код, отчёты и созданные игровые ассеты. Raw references остаются приватными, исключаются из Git и билдов.
- Встроенный image_gen разрешён с фотографиями всех предоставленных персонажей. Это не разрешает произвольные сторонние сервисы, платные CLI/API, покупки или копирование raw-фотографий в публичный репозиторий.
- Разрешён автоматический squash merge фазового PR после независимого Lead Review точного текущего SHA/base, всех обязательных CI и проверки нерешённых критических замечаний. GitHub rules, требуемые ручные approvals и права обязательны; force push/admin override запрещены.
- Продолжение P07 условно разрешено только после полного P06/подтверждённого merge и независимого FULL Production Readiness. Lead должен утвердить21MDS до массового производства. Текущий stopP06 сохраняет эти gates до проверенного handoff.

Публичный репозиторий с игровыми ассетами не является разрешением на storefront/публичный игровой релиз или клонирование реальных голосов. Самостоятельное likeness-принятие новых материалов не выводится из права пользоваться image_gen. Имена/изображения/голоса для широкого релиза проверяются отдельно; реальные голоса не синтезируются и не имитируются. Новые расходы/release не разрешены.

Исторический P01 artistic signoff: владелец ответил «топ продолжаем если можем» на present/past/world previews; независимый Lead проверил контекст и хеши, P01 PASSattempt2. Это принятие конкретных PNG для разработки; не разрешение публичного релиза или реальных голосов. Evidence reports/phases/P01/human_art_review_response.json и decision-attempt2.json сохраняется.
